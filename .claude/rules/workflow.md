# Working agreements (every session)

- Work one plan step at a time, on its own branch with its own PR. Stop for the owner's review, and never merge without their go-ahead.
- Discuss assumptions and open decisions before implementing, **one question at a time**, each with a recommendation.
- When a step changes a decision, update `docs/plan/` (and `docs/vision.md` if needed) in the same PR.
- Check facts about libraries and tools against current sources before stating them.
- Commits use the repo's git config (GitHub noreply email). Never commit secrets.
